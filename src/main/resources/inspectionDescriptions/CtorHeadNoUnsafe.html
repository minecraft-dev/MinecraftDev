Reports when @At("CTOR_HEAD") is missing unsafe

Sponge Mixin restricts where injectors can inject into constructors, and CTOR_HEAD fails without unsafe = true. Fabric's version of Mixin doesn't have this restriction, so by default this inspection is disabled when Fabric Mixin is present. 


@Inject(method = "<init>", at = @At("CTOR_HEAD"))          // bad
@Inject(method = "<init>", at = @At(value = "CTOR_HEAD", unsafe = true)) // good
