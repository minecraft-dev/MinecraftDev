Detect wrong argument types in translation arguments

Translation arguments must be a String, Number, Boolean or Component. Minecraft can't serialize arguments of other types, which causes errors, for example when the component is sent over the network. Convert such arguments to strings, or use Component.translatableEscape. 


Component.translatable("my_mod.position", pos)                 // bad
Component.translatable("my_mod.position", String.valueOf(pos)) // good
