Checks that @ModifyVariable has argsOnly if it targets arguments, which improves performance of the mixin

With argsOnly = true, Mixin only searches the method's parameters, so it doesn't have to analyze the local variables of the target method. 


// bad
@ModifyVariable(method = "setName", at = @At("HEAD"))
private String modifyName(String name) { ... }

// good
@ModifyVariable(method = "setName", at = @At("HEAD"), argsOnly = true)
private String modifyName(String name) { ... }
