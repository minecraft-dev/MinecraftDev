All implementations of IMessage and IMessageHandler must have an empty constructor

When a message is received, Forge creates the message and its handler using their empty constructors, before reading the message's contents. Without an empty constructor, this fails. 


public class MyMessage implements IMessage {
    private int value;

    public MyMessage() {} // required

    public MyMessage(int value) {
        this.value = value;
    }
    ...
}
