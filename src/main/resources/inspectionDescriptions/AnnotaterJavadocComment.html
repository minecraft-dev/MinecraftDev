Reports comments in the annotater Javadoc editor that are not Markdown documentation comments (///)

Annotater stores its Javadocs as Markdown, so only Markdown documentation comments can be saved to the annotater checkout. Traditional Javadoc comments (/** */), line comments and block comments are not supported.
