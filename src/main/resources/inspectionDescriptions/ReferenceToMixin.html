A Mixin class doesn't exist at runtime, and thus cannot be referenced directly.

Instead of the mixin class, use the target class, or an interface implemented by the mixin. 


// bad
((EntityMixin) (Object) entity).myMod$getData();

// good: EntityMixin implements MyModEntity
((MyModEntity) entity).myMod$getData();

Accessor mixins, and references from a mixin to its own super mixins, are allowed.
