Reports invalid @Mixin super classes.

The superclass of a mixin gives the mixin access to the members of a superclass of its target. It must therefore be a class in the hierarchy of every target class, and can't be the target class itself. If the superclass is another mixin, it must target a class in the hierarchy of every target class. 


class Animal {}
class Dog extends Animal {}

@Mixin(Dog.class)
class DogMixin extends Animal {}   // good

@Mixin(Dog.class)
class DogMixin extends AnimalMixin {} // good

@Mixin(Dog.class)
class DogMixin extends Dog {}      // bad: extends the target class

@Mixin(Dog.class)
class DogMixin extends Vehicle {}  // bad: not in Dog's hierarchy
