Methods which are declared with a @SideOnly annotation can only be used in matching @SideOnly classes and methods.

Code annotated with @SideOnly is removed when running on the other side, so code that uses it crashes there. 


// bad: runs on both sides
public void update() {
    getRenderer().render(); // render() is @SideOnly(Side.CLIENT)
}

// good
@SideOnly(Side.CLIENT)
public void update() {
    getRenderer().render();
}
