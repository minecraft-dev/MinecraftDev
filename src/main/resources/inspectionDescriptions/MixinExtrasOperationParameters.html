Operation.call called with the wrong parameter types

Operation.call accepts any arguments at compile time, but at runtime they must match the parameters of the wrapped operation: the receiver, if any, followed by the arguments of the original call. Otherwise the call fails with an exception. 


// target: this.setHealth(health);

@WrapOperation(method = "foo", at = @At(value = "INVOKE", target = "..."))
private void wrapSetHealth(Entity entity, float health, Operation<Void> original) {
    original.call(health);         // bad
    original.call(entity, health); // good
}
