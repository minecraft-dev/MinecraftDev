Reports methods annotated with a different @SideOnly side than their class, and methods returning a type annotated with a different @SideOnly side than the method or its class.

A class annotated with @SideOnly is removed together with everything in it on the other side, so a method in it can't be for a different side, and @SideOnly annotations on its methods are usually useless. Likewise, a method can't return a type that doesn't exist on its side. 


@SideOnly(Side.SERVER)
public class ServerData {
    @SideOnly(Side.CLIENT) // bad
    public void render() { ... }
}
