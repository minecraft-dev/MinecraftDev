Reports member references in Mixin annotations that Mixin can't parse.

Mixin fails to apply an annotation whose method or target it can't parse. A member reference consists of an optional owner class, the member name and an optional descriptor, in one of these forms:

  • Lcom/example/ExampleClass;execute(II)V
    • for methods
  • Lcom/example/ExampleClass;count:I
    • for fields

The name can be followed by a quantifier such as *. Regex selectors, such as /^execute$/, and dynamic selectors, such as @Desc(id), are also supported. 


@At(value = "INVOKE", target = "com.example.ExampleClass#execute")      // bad
@At(value = "INVOKE", target = "Lcom/example/ExampleClass;execute(II)V") // good
