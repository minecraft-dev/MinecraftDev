@Inject into Constructor

Reports @Inject injectors that inject into a constructor at an instruction other than RETURN, without unsafe = true.

Sponge Mixin only allows @Inject into constructors at RETURN by default, because injecting earlier risks running code before the object is initialized. Fabric's version of Mixin doesn't have this restriction, so by default it is allowed when Fabric Mixin is present. 


@Inject(method = "<init>", at = @At(value = "INVOKE", target = "..."))                // bad
@Inject(method = "<init>", at = @At(value = "INVOKE", target = "...", unsafe = true)) // good
@Inject(method = "<init>", at = @At("RETURN"))                                         // good
