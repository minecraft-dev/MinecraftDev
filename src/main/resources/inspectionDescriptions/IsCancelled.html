Reports useless event cancellation checks

Some event listeners only receive events that are not canceled, so checking whether the event is canceled always gives the same result. On Bukkit, this applies to handlers with ignoreCancelled = true. On Sponge, listeners only receive events that are not canceled, unless annotated with @IsCancelled. 


@EventHandler(ignoreCancelled = true)
public void onBreak(BlockBreakEvent event) {
    if (event.isCancelled()) { // always false
        return;
    }
    ...
}
