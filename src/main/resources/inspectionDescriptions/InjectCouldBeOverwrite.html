Reports when an @Inject can be written as an @Overwrite

Such an @Inject effectively replaces the target method, so any other mod's injectors into the target method silently stop working. An @Overwrite makes this explicit, and Mixin reports conflicts between overwrites. 


// bad
@Inject(method = "getSpeed", at = @At("HEAD"), cancellable = true)
private void getSpeed(CallbackInfoReturnable<Float> cir) {
    cir.setReturnValue(2.0f);
}

// good
/**
 * @author MyMod
 * @reason Double the speed
 */
@Overwrite
public float getSpeed() {
    return 2.0f;
}
