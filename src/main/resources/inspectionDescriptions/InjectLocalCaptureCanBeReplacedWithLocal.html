Reports when @Inject local capture can be replaced with @Local

Local capture requires the injector to declare every local variable up to the ones it needs, in order, so it breaks whenever the local variables of the target method change. @Local captures only the locals that are needed. 


// bad
@Inject(method = "foo", at = @At("TAIL"), locals = LocalCapture.CAPTURE_FAILHARD)
private void onFoo(CallbackInfo ci, int i, String name, List<String> list) {
    System.out.println(name);
}

// good
@Inject(method = "foo", at = @At("TAIL"))
private void onFoo(CallbackInfo ci, @Local String name) {
    System.out.println(name);
}
