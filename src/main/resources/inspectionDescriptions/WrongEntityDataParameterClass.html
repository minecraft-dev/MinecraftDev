Reports when the class passed to a synched entity data definition is not the same as the containing entity class.

Synched entity data is numbered per entity class, based on how many parameters that class and its superclasses define. Defining a data accessor with a different class can give it an ID that conflicts with another accessor, which breaks entity data syncing. 


public class MyEntity extends Entity {
    // bad
    private static final EntityDataAccessor<Integer> DATA = SynchedEntityData.defineId(Entity.class, EntityDataSerializers.INT);

    // good
    private static final EntityDataAccessor<Integer> DATA = SynchedEntityData.defineId(MyEntity.class, EntityDataSerializers.INT);
}
