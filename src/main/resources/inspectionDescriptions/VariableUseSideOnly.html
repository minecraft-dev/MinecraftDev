Reports uses of fields annotated with @SideOnly, or declared in a class annotated with @SideOnly, in classes or methods that are annotated differently, or not at all.

Code annotated with @SideOnly is removed when running on the other side, so code that uses it crashes there. 


@SideOnly(Side.CLIENT)
private int renderColor;

// bad: runs on both sides
public int getColor() {
    return renderColor;
}

// good
@SideOnly(Side.CLIENT)
public int getColor() {
    return renderColor;
}
