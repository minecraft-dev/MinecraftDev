Unnecessary mutable reference to captured local

Reports @Local parameters of a LocalRef type whose value is only read, never set.

A mutable reference makes MixinExtras wrap the local in a reference object and write its value back afterwards. If the value is never set, capture the local directly. 


// bad
private void onFoo(CallbackInfo ci, @Local LocalIntRef count) {
    System.out.println(count.get());
}

// good
private void onFoo(CallbackInfo ci, @Local int count) {
    System.out.println(count);
}
