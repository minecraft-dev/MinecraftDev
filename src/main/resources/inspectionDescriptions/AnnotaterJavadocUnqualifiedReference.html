Reports classes referenced in annotater Javadocs without their fully qualified name

Annotater Javadocs are applied to Minecraft sources that may have different imports to the file they were written in, so annotater requires every class referenced from a Javadoc to be written with its fully qualified name. Fully qualified names can still be shown shortened in the inlay hints, depending on the annotater settings.
