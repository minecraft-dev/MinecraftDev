Reports enum constants that are not properly prefixed by the mod id

Enum constants added by mixins share the target enum with constants added by every other mod. Prefixing their names with the mod id avoids conflicts between mods that add constants with the same name. The required pattern can be configured. 


@Mixin(Color.class)
enum ColorMixin {
    PURPLE,       // bad
    MY_MOD_PURPLE // good
}
