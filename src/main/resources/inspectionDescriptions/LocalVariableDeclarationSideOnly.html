A variable whose class declaration is annotated with @SideOnly for one side cannot be declared in a class or method that does not match the same side.

Code annotated with @SideOnly is removed when running on the other side, so code that uses it crashes there. 


// bad: runs on both sides
public void update() {
    Minecraft mc = Minecraft.getMinecraft(); // Minecraft is @SideOnly(Side.CLIENT)
}

// good
@SideOnly(Side.CLIENT)
public void update() {
    Minecraft mc = Minecraft.getMinecraft();
}
