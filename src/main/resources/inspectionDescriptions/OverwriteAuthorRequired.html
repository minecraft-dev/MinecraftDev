For maintainability reasons, the Sponge project requires @Overwrite methods to declare an @author JavaDoc tag.

An @Overwrite replaces the target method entirely and can conflict with other mods. The @author tag says who to contact about the overwrite, and the @reason tag explains why it was needed. 


/**
 * @author MyMod
 * @reason Fix the speed calculation for slow entities
 */
@Overwrite
public float getSpeed() { ... }
