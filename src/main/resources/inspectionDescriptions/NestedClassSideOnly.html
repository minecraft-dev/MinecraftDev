Reports nested classes annotated with a different @SideOnly side than their containing class.

A class annotated with @SideOnly is removed together with everything in it on the other side, so a nested class can't be for a different side. @SideOnly annotations on nested classes are therefore usually useless. 


@SideOnly(Side.CLIENT)
public class Renderer {
    @SideOnly(Side.SERVER) // bad
    public static class Data { ... }
}
