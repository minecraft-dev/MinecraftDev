Reports duplicate @Interface prefixes in an @Implements annotation.

Methods whose name starts with an @Interface prefix are renamed when the mixin is applied, to soft-implement a method of that interface. If two interfaces share a prefix, it is ambiguous which interface a prefixed method belongs to. 


@Implements({
    @Interface(iface = Foo.class, prefix = "foo$"),
    @Interface(iface = Bar.class, prefix = "foo$") // Duplicate prefix 'foo$'
})
