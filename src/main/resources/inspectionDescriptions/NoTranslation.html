Reports translation keys that don't have a translation.

If a translation key doesn't exist, Minecraft displays the key itself instead of a translated text. This is usually caused by a typo in the key, or a translation missing from the language file. 


// en_us.json: { "my_mod.greeting": "Hello!" }
Component.translatable("my_mod.greting") // bad
Component.translatable("my_mod.greeting") // good
