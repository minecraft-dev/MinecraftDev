Reports ambiguous references in Mixin annotations

When a method name matches several overloads in the target class, Mixin targets all the overloads, which is often not intended. Specify the descriptor to target a specific overload, or add the * wildcard to explicitly target all of them. 


@Inject(method = "add", ...)                     // bad
@Inject(method = "add(Ljava/lang/String;)V", ...) // good: one overload
@Inject(method = "add*", ...)                    // if all overloads are intended
