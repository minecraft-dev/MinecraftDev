Reports missing or unused cancellable @Inject usages

Calling cancel() or setReturnValue() on the callback info of an @Inject that is not marked cancellable = true throws an exception at runtime. Conversely, an @Inject marked cancellable = true that is never canceled makes Mixin generate an unnecessary check in the target method. 


// bad
@Inject(method = "foo", at = @At("HEAD"))
private void onFoo(CallbackInfo ci) {
    ci.cancel();
}

// good
@Inject(method = "foo", at = @At("HEAD"), cancellable = true)
private void onFoo(CallbackInfo ci) {
    ci.cancel();
}
