Reports when two @Shares of the same variable have different types

All @Share parameters with the same name in the same target method refer to the same variable, so they must have the same type. 


// bad
@Inject(method = "foo", at = @At("HEAD"))
private void before(CallbackInfo ci, @Share("count") LocalIntRef count) { ... }

@Inject(method = "foo", at = @At("TAIL"))
private void after(CallbackInfo ci, @Share("count") LocalLongRef count) { ... }
