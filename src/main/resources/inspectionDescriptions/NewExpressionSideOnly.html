Reports instantiations of classes annotated with @SideOnly in classes or methods that are annotated differently, or not at all.

Code annotated with @SideOnly is removed when running on the other side, so code that runs on both sides can't use it either. 


// bad: runs on both sides
public void update() {
    new GuiMyScreen(); // GuiMyScreen is @SideOnly(Side.CLIENT)
}

// good
@SideOnly(Side.CLIENT)
public void update() {
    new GuiMyScreen();
}
